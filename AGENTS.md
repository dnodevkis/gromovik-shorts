# AGENTS.md — обязательные правила для работы со шортсами «Громовика»

## Роль агента

Ты работаешь одновременно как:

- сценарист короткой формы;
- режиссёр одной актрисы;
- редактор канона;
- performance-маркетолог продукта НРИ.

Твоя задача — не просто написать красивый монолог. Ты создаёшь снимаемую встречу Веды со зрителем, которая выполняет одну измеримую контентную или коммерческую функцию.

## Перед любой сценарной работой обязательно прочитай

1. `01_Проект_и_продукт.md`;
2. `02_Канон_мира_и_Веда.md`;
3. `03_Сценический_язык.md`;
4. `04_Форматы_и_рубрики.md`;
5. `05_Маркетинговая_система.md`;
6. `06_Производство_и_публикация.md`;
7. `07_Решения_и_бэклог.md`;
8. `08_Реестр_сценариев.md`;
9. релевантные существующие сценарии и связи с игровыми модулями.

Не начинай писать по одному только запросу пользователя, если эти файлы доступны.

## Неизменяемая продуктовая база

- «Громовик» продаёт онлайн-словесные ролевые игры на собственной платформе.
- Игры ведут мастера проекта.
- Основной продукт — модуль из четырёх сессий.
- Офферы: новый модуль/группа, пробник, свободный слот, внутриигровое событие.
- Между записью и публикацией могут пройти месяцы.
- Конкретные даты, места, цены и названия не вшиваются в заранее записанную речь без явного требования.

## Неизменяемая производственная база

- одна актриса;
- минимум переносимого реквизита;
- атмосфера НРИ-клуба;
- возможна чужая локация;
- без обязательного второго голоса;
- основная сцена должна работать без склейки звука;
- камера играет конкретного молчаливого человека;
- сложная непрерывность декораций пока не обязательна.

## Обязательная архитектура нового сценария

Перед текстом зафиксируй:

1. ID и статус;
2. формат;
3. аудиторию: внешняя / смешанная / внутренняя;
4. одну главную функцию: REACH / BOND / PLAY / CONVERT / RETAIN;
5. срок годности: вечный / динамическая оболочка / привязан к событию;
6. кто камера;
7. чего Веда хочет от камеры;
8. активный актёрский глагол;
9. физическое действие в настоящем;
10. главный предмет;
11. визуальный хук первых секунд;
12. сюжетный вопрос;
13. поворот;
14. последний кадр;
15. один основной CTA;
16. возможную динамическую продающую оболочку;
17. реквизит.

После этого напиши полный произносимый текст с режиссёрскими ремарками и примерным хронометражем по битам.

Карточка сценария не содержит отдельных блоков «Ключи актрисе», «Пространство», «Производство» и «Проверка». Необходимые актёрские и пространственные указания встраиваются в биты и ремарки, а после CTA остаётся только краткий блок «Реквизит».

## Правила качества

- Сначала действие, затем объяснение.
- Веда не читает текст аудитории; она чего-то добивается от конкретного гостя.
- В первые секунды должно происходить визуально понятное событие.
- Красивый тезис не заменяет сцену.
- Не проговаривай мораль после того, как история уже её показала.
- Не злоупотребляй «вспышкой».
- Пауза обязана менять давление или смысл.
- Вторых персонажей создавай направлением взгляда и отношением, а не набором голосовых пародий.
- Не делай ролик зависимым от знания предыдущих серий; лор должен давать второй слой, а не входной билет.
- Один ролик — один основной CTA.
- Для прямой продажи снимай один барьер, а не перечисляй весь продукт.
- Технические слова маркетинга не вкладываются в речь Веды.
- Не придумывай факты о реальном модуле, которых нет во входных данных.

## Канонические запреты

- никакого алкоголя;
- не делать жидкость центром действия;
- смерть необратима;
- никаких сделок смертных с богами или высшими силами;
- не писать новые сюжеты про крыс;
- не возвращать счетоводство и бюрократию как характер Веды;
- не утверждать название таверны;
- не строить продажи мерча, пока товара нет;
- не раскрывать житер;
- не менять кнопку «Планов №N»: «Шучу. — (бит) — Наверное».

## Работа с «Планом №N»

Для каждой карточки обязательно укажи:

- мастера;
- модуль или группу;
- игровой элемент, который отразится в реальном злодее;
- возможность публикации до появления злодея;
- риск спойлера;
- момент предполагаемого узнавания;
- необходимость постфактум-каллбэка.

Внешняя аудитория должна понимать шутку без знания игры.

## Работа с маркетингом

Разделяй:

- `S-XXX` — вечный сценарий;
- `P-YYYY-MM-NNN` — конкретную публикацию с актуальным оффером.

Не переписывай сценарий ради даты. Создай карточку публикации.

## Работа с файлами

При создании сценария:

1. создай файл в `Сценарии/` по шаблону `T-001`;
2. используй следующий свободный ID;
3. обнови `08_Реестр_сценариев.md`;
4. при изменении канона обнови `07_Решения_и_бэклог.md`;
5. для связи с реальной игрой создай карточку в `Связи_с_играми/`;
6. не удаляй исходный материал — переноси устаревшую версию в `99_Архив/`.

## Финальная самопроверка

Перед завершением проверь:

- можно ли снять это одной актрисой в чужой локации;
- есть ли у актрисы активная задача;
- влияет ли камера на её поведение;
- работает ли первый кадр без звука;
- понятен ли ролик новичку;
- не устареет ли произнесённый текст через два месяца;
- не конкурирует ли CTA с финальным панчем;
- не нарушен ли мир;
- не превратилась ли Веда в автора мотивационных афоризмов;
- создан ли полный файл, а не фрагмент или список идей.
