# «Громовик»: workspace шортсов

Версия структуры: **1.0**  
Дата фиксации: **2026-08-16**

Этот workspace разделяет четыре вещи, которые раньше жили в одном рабочем документе:

1. **канон мира и Веды** — что нельзя самовольно менять;
2. **сценарий** — вечное содержимое, которое можно снять заранее;
3. **постановку** — задача актрисы, камера, предмет, паузы, мизансцена;
4. **публикацию и продажу** — актуальный оффер, титр, подпись, закреплённый комментарий.

Главный принцип проекта:

> Мы снимаем не монологи Веды, а встречи зрителя с Ведой.  
> Вечное ядро снимается заранее; изменяемая продающая оболочка добавляется в день публикации.

## Что продаёт проект

«Громовик» продаёт **онлайн-словесные ролевые игры на собственной платформе**, которые ведут мастера проекта. Основной продукт — **модуль из четырёх сессий**.

В публикациях могут продвигаться:

- новый модуль или новая группа;
- пробная игра;
- освободившееся место в действующей группе;
- внутриигровое событие для текущих игроков.

Конкретные даты, количество мест, цена, название группы и ссылка **не записываются в репликах Веды**, если ролик может выйти через несколько недель или месяцев.

## С чего начинать работу

### Для человека

1. Прочитать [01_Проект_и_продукт.md](01_Проект_и_продукт.md).
2. Прочитать [02_Канон_мира_и_Веда.md](02_Канон_мира_и_Веда.md).
3. Прочитать [03_Сценический_язык.md](03_Сценический_язык.md).
4. Для нового ролика выбрать формат в [04_Форматы_и_рубрики.md](04_Форматы_и_рубрики.md).
5. Создать карточку по [Шаблоны/T-001_Карточка_сценария.md](Шаблоны/T-001_Карточка_сценария.md).
6. После съёмки оформить отдельную карточку публикации — не переписывать сценарий под конкретную дату.

### Для агента

Корневой файл [AGENTS.md](AGENTS.md) содержит обязательный порядок чтения и правила внесения изменений. Полная версия навыка находится в [.agents/skills/gromovik-shorts/SKILL.md](.agents/skills/gromovik-shorts/SKILL.md). Для агента без поддержки файловых навыков подготовлен [PROMPT_ДЛЯ_СЦЕНАРНОГО_АГЕНТА.md](PROMPT_ДЛЯ_СЦЕНАРНОГО_АГЕНТА.md).

Помимо общего навыка есть три ролевых, вызываемых по отдельности:

- [.claude/skills/veda-dramaturg/SKILL.md](.claude/skills/veda-dramaturg/SKILL.md) — сценарист: жанр, классические приёмы, моноспектакль, компрессия;
- [.claude/skills/shorts-hook-marketer/SKILL.md](.claude/skills/shorts-hook-marketer/SKILL.md) — маркетолог: первый кадр, удержание, петли, оффер и оболочка публикации;
- [.claude/skills/one-take-director/SKILL.md](.claude/skills/one-take-director/SKILL.md) — режиссёр: мизансцена под неподвижную камеру, реквизит, вердикт о готовности к съёмке.

Порядок работы: сценарист пишет встречу → маркетолог правит вход и собирает оболочку → режиссёр выносит окончательное решение по кадру и реквизиту.

## Источники истины

При конфликте файлов действует следующий приоритет:

1. последнее явно записанное решение в `07_Решения_и_бэклог.md`;
2. канон в `02_Канон_мира_и_Веда.md`;
3. правила постановки, форматов и маркетинга;
4. отдельная карточка сценария;
5. архивный исходный документ.

Нельзя молча «исправлять» канон во время написания нового ролика. Предлагаемое изменение сначала оформляется как решение со статусом `на согласование`.

## Статусы сценариев

- `идея` — существует только замысел;
- `литературный черновик` — есть текст, но нет полноценной постановки;
- `готов к режиссёрской разборке`;
- `готов к читке` — прописаны цель, камера, действие и мизансцена;
- `готов к съёмке` — подтверждены реквизит, локация и длительность;
- `снят`;
- `готов к публикации` — выбрана актуальная оболочка;
- `опубликован`;
- `архив`.

## Перенесённые сценарии

Все литературно принятые материалы вынесены в отдельные карточки:

- `S-001 — С мёдом` — замена конфликтующего ролика «Молоко»;
- `S-002 — Провал`;
- `S-003 — Попутчик. Часть 1: Восьмой`;
- `S-004 — Попутчик. Часть 2: Три слова`;
- `S-005 — Оплата`;
- `S-006 — Древние крысы`;
- `S-007 — Собеседование`;
- `S-008 — Некромант`;
- `S-009 — Котёл`;
- `S-010 — Переводчик с геройского`;
- `S-011 — К этим` — новый черновик на обсуждении.

Первые десять находятся в статусе **`готов к читке`**: в карточках есть полный текст, блок «Встреча» с задачей актрисы и действием, хуки, поворот, CTA и краткий список реквизита. `S-011` хранится отдельно как черновик к обсуждению. Статус меняется на **`готов к съёмке`** только после читки с действием и подтверждения реальных реквизита, локации и длительности.
