# Связи с игровыми модулями

Эта папка хранит скрытый производственный слой между публичными роликами и реальными играми.

Особенно важна для:

- «Планов №N»;
- внутриигровых событий;
- злодеев с узнаваемыми планами;
- постфактум-каллбэков;
- проверки спойлеров.

Публичный сценарий не должен зависеть от доступа к этим файлам. Карточки могут содержать внутренние сведения и не предназначены для публикации.
