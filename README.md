# Gromovik Shorts

Рабочее пространство сценариев YouTube Shorts с Ведой для проекта онлайн-словесных ролевых игр «Громовик».

## Сайт

После публикации сайт доступен по адресу:

<https://dnodevkis.github.io/gromovik-shorts/>

Markdown-файлы остаются источником истины. При каждом push в `main` GitHub Actions собирает из них статический сайт и публикует его через GitHub Pages.

## Локальная сборка

```bash
npm install
npm run build
```

Готовый сайт появится в `dist/`. Эта папка не хранится в Git и каждый раз создаётся заново.

## Что публикуется

На сайт попадают девять сценариев в следующем порядке:

1. [S-002 — Провал](Сценарии/S-002_Провал.md)
2. [S-005 — Оплата](Сценарии/S-005_Оплата.md)
3. [S-006 — Древние крысы](Сценарии/S-006_Древние_крысы.md)
4. [S-007 — Собеседование](Сценарии/S-007_Собеседование.md)
5. [S-009 — Котёл](Сценарии/S-009_Котёл.md)
6. [S-010 — Переводчик с геройского](Сценарии/S-010_Переводчик_с_геройского.md)
7. [S-014 — Камень](Сценарии/S-014_Камень.md)
8. [S-012 — После героев](Сценарии/S-012_После_героев.md)
9. [S-017 — Житер](Сценарии/S-017_Житер.md)

Также публикуется [Канон мира и Веда](02_Канон_мира_и_Веда.md), главная страница и каталог этих сценариев.

Явный список публикуемых файлов и порядок сценариев заданы в `scripts/build-site.mjs`. При изменении состава обновите этот список, ссылки в `site/index.md` и этот раздел README.

Остальные сценарии, проектные документы, реквизит, производственные материалы, архив и инструкции остаются в репозитории. Они не включаются в сборку сайта и недоступны на нём по прямым ссылкам.
