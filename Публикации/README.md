# Публикации

Здесь хранятся не сценарии, а конкретные выпуски с актуальной маркетинговой оболочкой.

Имя файла:

```text
P-YYYY-MM-NNN_S-XXX_краткое-назначение.md
```

Пример:

```text
P-2026-09-014_S-002_пробная-игра.md
```

Один и тот же сценарий может иметь несколько публикационных карточек, если меняется оффер или площадка. Исторические показатели не перезаписываются.
